# MERN Calculator

A simple and responsive calculator application built using the MERN (MongoDB, Express.js, React.js, Node.js) stack.

## Features
- Perform basic arithmetic operations: Addition, Subtraction, Multiplication, Division.
- Responsive design for mobile and desktop usage.
- Real-time updates and results.
- Backend integration for storing history (optional).

## Tech Stack
- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Styling**: TailwindCSS
